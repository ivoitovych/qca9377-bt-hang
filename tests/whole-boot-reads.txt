# tests/whole-boot-reads.txt — every journal read in the tools that names a boot (or passes
# an argument array) and is bounded by none of --grep, -n, --since, --until, -p or a `| head`.
#
# On the laptop a boot runs for days with dynamic debug on, and such a read takes minutes:
# that is how a close lost EX-023's row, how bt-trial-audit took 7 min, and why a tools-only
# deploy looked hung (I2). Some reads are whole by design (an export, a snapshot of a boot);
# which ones is a decision about each tool, and each line here waits for it:
#   <file> TAB <the read, continuation lines joined, whitespace collapsed> TAB <reason>
# "pending" until the read is bounded (then delete the line) or given its reason here. The
# suite (RT3) fails on a read that is not listed, and on a listed read the tools no longer
# make. The review IDs are the review of 2026-10-19's findings for that tool.
#
# Found 2026-10-19 by the scan in tests/run-tests (wb_scan): 41 reads in 21 files.
