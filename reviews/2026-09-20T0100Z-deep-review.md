
That run was **green**. The three assertions — no retired BT-1/reset sentences in the
current-facing files, no project labels in the bug report, labels only as parenthetical
handles elsewhere — used `rg … || true`: the failed command became an empty string, and an
empty string was "nothing found". They have never actually run in CI since the label gate was
added on 2026-09-14; they ran only on the machine, where `rg` exists. This is the
analysis-failure-as-zero-result shape the suite's own rules forbid, found in the suite.

Fixed: the three searches use `grep -E` (present on every host) and read the exit code —
`1` is the negative result, `0` fails on the matches, `2` fails as a broken search. A fourth
invariant asserts the suite invokes no `rg`. `scripts/prove-neg-search.sh` runs the same
searches standalone and prints each exit code (its output is in the commit that carries this
file); `scripts/ci-log-search.sh` is the tool that fetched the evidence above — a full-log
search a red `--failed` cannot do, because the lines hid inside a step that passed.

## The follow-up (2026-09-20T02:00Z) — three residuals, all real, all fixed

Verbatim: [`2026-09-20T0200Z-deep-review-followup-verbatim.md`](2026-09-20T0200Z-deep-review-followup-verbatim.md).
The reviewer accepted the response and named three residuals in the response itself:

- **DP-07** — the new anti-`rg` guard scanned only `$0` (the UT-12 split would have moved
  tests out from under it) and matched only `rg -…`/`rg '…'`, not `rg "…"` or `rg pattern`.
  Now it reads `${SUITE_FILES[@]}` like every other self-check and matches the `rg` token at a
  command start whatever follows. `scripts/prove-neg-search.sh` carries a positive control:
  three shapes in a temp file, all detected.
- **DP-08** — the proof scripts hardcoded this machine's checkout path, so an external reviewer
  could not run them "standalone"; and `ci-log-search.sh` could cache a failed `gh` download's
  error text as the log. Every script under `scripts/` now derives the checkout from
  `BASH_SOURCE`; the download goes to a temp file and is moved into place only on success.
- **DP-09** — `fix-proposal.md`'s heading still read "Fix proposal"; renamed "Historical fix
  proposal — superseded by upstream `dc16388d45ec`". And "destroying this device" overstated
  the record: what `EX-023`/`EX-026` show is a late reset driving an already-wedged controller
  off the USB bus until power is removed, after which it works again. That phrase replaces
  "destroy" in every current-facing file (seven of them); HISTORY and exhibits keep the
  contemporary wording as written.
